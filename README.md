# 轻笺 QuickNotes

Windows 桌面便签内测版：普通便签、待办列表、提醒、全文搜索、彩色皮肤、透明模式、靠边隐藏与本地自动保存。

## 下载

前往 [Releases](https://github.com/pg951213-eng/QuickNotes/releases) 下载 Windows 安装程序。内测版本标记为 Pre-release。

安装前从系统托盘退出旧版。首次启动会迁移原有便签，并保留原始文件和迁移备份。

## 在线更新

从 0.2.0-beta.2 开始，客户端已配置本仓库作为更新源。打开设置，选择“检查更新”，下载后可选择“重启并更新”。更早版本需要手动安装一次。

## 内测范围

便签保存在设备本地的 SQLite 数据库中。账号登录、云存储和多端同步尚未接入。本仓库仅用于发布应用和问题反馈，不接收私人便签数据。
